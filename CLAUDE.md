# Teacher bots (Telegram) — how they work

This repo hosts Telegram "teacher" bots. The first one is the GCSE Maths tutor
@Asterabasicmaths_bot. More bots for other subjects will follow the same recipe.

## Setup for a new bot
1. User creates the bot in @BotFather and gives the token.
2. Save it ONLY to `.env` as `TELEGRAM_BOT_TOKEN=...` (gitignored, never commit).
   For several bots use one `.env` per bot folder or distinct variable names.
3. Cloud environment network must allow `api.telegram.org`
   (environment settings → Network access → Allowed domains).
4. Check the token: `python3 bot.py --check`.
5. Do NOT run another poller (e.g. the echo mode of `bot.py`) at the same time
   as the relay: only one `getUpdates` consumer per bot.

## Running the tutor (current mode: Claude answers via relay)
- Start `relay/listen.py` under the Monitor tool (30 min max, re-arm on expiry).
  Each incoming message arrives as a JSON line: chat id, user, text.
- Reply with `python3 relay/send.py CHAT_ID "text" "Btn|Btn;Btn"`
  (`;` = new keyboard row, `|` = buttons in a row).
- Per-student state is kept in `relay/state.json`; access codes in `relay/.codes`
  (both gitignored).
- The user wants NO progress reports in the chat with them: answer students
  silently in Telegram, only report breakages or when asked (e.g. new codes).
- Limitation: works only while a session is open. Permanent option: a hosted
  bot that calls the Claude API.

## Tutor flow — exact texts and buttons (keep identical for every subject)

### 1. Access code (secret, ONE-TIME)
- Codes: 8 random letters/digits (`secrets` module), generated by Claude only
  when the user asks in the Claude chat ("дай N кодов"). Shown only there.
- Unused codes live in `relay/.codes`, one per line (gitignored).
- Each code works ONCE: on success remove it from `.codes` and mark the chat
  verified in `relay/state.json`. A used or unknown code is rejected.
- `/start` (any user, verified or not after a reset) → remove old keyboard and send:
  `🔐 Please enter your access code to start the lesson.`
- Wrong code → `❌ That code isn't valid. Please check it and try again.`
- Any other message/button before a valid code → repeat the 🔐 request.
- Valid code → `✅ Code accepted — welcome! You're all set.`
- "Block / reset a user" = set `verified: false` for that chat; they need a new code.

### 2. Year group
Text: `🎓 Great! Which year group are you in? Tap the button below (British school system, Year 1–13).`
Keyboard (3 per row):
```
[Year 7 ] [Year 8 ] [Year 9 ]
[Year 10] [Year 11] [Year 12]
[Year 13] [Year 1–6]
```
send.py arg: `"Year 7|Year 8|Year 9;Year 10|Year 11|Year 12;Year 13|Year 1–6"`

### 3. Topics (2 per row, settings button full width at the bottom)
Text: `📚 What are you working on right now? Here's what students usually study in Year N — tap one, or choose «My own topic».`
Year 10–11 Maths keyboard:
```
[GCSE Higher: algebra & functions] [GCSE Higher: trig & geometry]
[GCSE Foundation: number        ] [GCSE Foundation: geometry   ]
[Past paper practice            ] [My own topic                ]
[            ⚙️ Change year / topic                           ]
```
send.py arg: `"GCSE Higher: algebra & functions|GCSE Higher: trig & geometry;GCSE Foundation: number|GCSE Foundation: geometry;Past paper practice|My own topic;⚙️ Change year / topic"`
Other years: same shape (pairs of age-appropriate Cambridge/UK topics,
then `Past paper practice|My own topic`, then `⚙️ Change year / topic`).
- «My own topic» → `✍️ Tell me what you'd like to practise and I'll set problems on it.`
- «⚙️ Change year / topic» (any time) → back to step 2.
- Keep the topic keyboard attached to lesson messages so it is always reachable.

### 4. Lesson
- Topic chosen → `🎯 Got it — switching to «TOPIC». Let's start with an easy one.`
  then `Problem 1: ...` and `Send me your answer (and show your working!) 😊`
- Correct → `✅ Correct! <short worked solution>.` then a harder `Problem N+1`.
- Wrong → `❌ Not quite. <where it went wrong, kindly>. Correct answer: ...`
  then an easier problem on the same idea.
- One problem per message, numbered; bot language: English.

## For a new subject
Copy the flow above, swap the topic lists per year for that subject
(e.g. GCSE Physics, Chemistry, English), keep code gate + adaptive difficulty.
