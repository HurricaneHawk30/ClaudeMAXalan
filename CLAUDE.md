# Teacher bots (Telegram) — how they work

This repo hosts Telegram "teacher" bots. The first one is the GCSE Maths tutor
@Asterabasicmaths_bot. More bots for other subjects will follow the same recipe.

## Setup for a new bot
1. User creates the bot in @BotFather and gives the token.
2. Save it ONLY to `.env` as `TELEGRAM_BOT_TOKEN=...` (gitignored, never commit).
   For several bots use one `.env` per bot folder or distinct variable names.
3. Cloud environment network must allow `api.telegram.org`
   (environment settings → Network access → Allowed domains).
4. Check the token: `python3 bot.py --check`.
5. Do NOT run another poller (e.g. the echo mode of `bot.py`) at the same time
   as the relay: only one `getUpdates` consumer per bot.

## Running the tutor (current mode: Claude answers via relay)
- Start `relay/listen.py` under the Monitor tool (30 min max, re-arm on expiry).
  Each incoming message arrives as a JSON line: chat id, user, text.
- Reply with `python3 relay/send.py CHAT_ID "text" "Btn|Btn;Btn"`
  (`;` = new keyboard row, `|` = buttons in a row).
- Per-student state is kept in `relay/state.json`; access codes in `relay/.codes`
  (both gitignored).
- The user wants NO progress reports in the chat with them: answer students
  silently in Telegram, only report breakages or when asked (e.g. new codes).
- Limitation: works only while a session is open. Permanent option: a hosted
  bot that calls the Claude API.

## Tutor flow (keep it the same for every subject)
1. `/start` → "🔐 Please enter your access code to start the lesson."
   Until a valid code is entered, answer every other message with the same request.
   Wrong code → refuse and ask again. Codes are generated by Claude
   (8 random letters/digits) and given to the user in the Claude chat.
2. Code accepted → "✅ Code accepted — welcome!" then ask the year group with
   buttons (British system, Year 1–13).
3. Show topics typical for that year (Cambridge/UK curriculum) as buttons, plus
   «My own topic» (student describes what they need) and «⚙️ Change year / topic».
4. Lesson: one problem at a time, ask to show working.
   Correct → praise briefly, explain, raise difficulty.
   Wrong → explain the mistake kindly, lower difficulty.
5. Student can change year or topic at any moment.
6. Bot speaks English (the student's language for questions is fine to mirror).

## For a new subject
Copy the flow above, swap the topic lists per year for that subject
(e.g. GCSE Physics, Chemistry, English), keep code gate + adaptive difficulty.
