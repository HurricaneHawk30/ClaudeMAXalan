# video05 — The Oldest Places Still in Use Today: план кадров

Текст диктора — `script_original.txt` (12 разделов, ~1765 слов, ≈12 мин). Кадры собираются в задаче 10 (`visuals/src/<папка>/`).

Правила — как в video04: без портретов и крупных лиц (жители Таоса, монахи, студенты, посетители — только общими планами или со спины). Внутри Таос-Пуэбло без жителей крупным планом. Для Катерины — без икон с ликами крупно, лучше стены, гора, двор, рукописи.

Порядок «каждое старше предыдущего» — главная фишка видео. На каждом месте в левом нижнем углу плашка с возрастом (Oswald, #F2A93B на #0E1116, появляется вместе с заголовком «Number …»):

Схемы (кодом, в фирменных цветах, как карты):
- 07: вид сверху на реку: «Рыбий рот» делит поток, стрелки «внутренний канал → поля», «внешний → река»; две подписи DRY SEASON 60% / 40% и FLOOD 40% / 60%.
- 08: разрез канат: склон холма, водоносный слой, «материнский» колодец ≈300 м, ряд вертикальных шахт, пологий туннель к полям; рядом силуэт Эйфелевой башни той же высоты.

Карты: как в video04 (глобус → страна → точка).
