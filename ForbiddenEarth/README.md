# Forbidden Earth — рабочая папка канала

Англоязычный документальный YouTube-канал без лица: подборки самых опасных и самых красивых мест Земли.

## Кто что делает
- **Алан** — владелец канала: даёт команды, утверждает результаты, загружает видео на YouTube.
- **Claude в чате claude.ai** (проект Business) — планирует, пишет сценарии, ставит задачи в `TASKS.md` и проверяет результаты.
- **Claude Code** (облако) — выполняет задачи из `TASKS.md`: озвучка, поиск кадров, монтаж.

## Как работаем
1. Вся работа идёт в ветке `claude/forbidden-earth`. Ветку `main` не трогаем.
2. Перед началом: `git pull origin claude/forbidden-earth`.
3. Задачи лежат в `TASKS.md`. Берётся первая задача со статусом `TODO`.
4. После задачи: статус меняется на `DONE`, под задачей пишется короткий отчёт (что сделано, где лежит, что проверить), затем коммит и push в `claude/forbidden-earth`.
5. Если нужно решение Алана (оплата, доступ к сайту, вход в аккаунт) — статус `BLOCKED` и вопрос в отчёте.

## Правила для файлов
- Структура: `ForbiddenEarth/videoNN/` → `script/`, `voice/`, `visuals/`, `render/`.
- Файлы больше 45 МБ в git не кладём (GitHub предупреждает с 50 МБ, жёсткий лимит 100 МБ, а каждая версия остаётся в истории навсегда). Полное видео остаётся в облаке, в репозиторий идёт сжатая копия для проверки.
- Никаких ключей, токенов и паролей в репозитории.
- Для каждого использованного кадра — строка в `credits.txt`: название, автор, лицензия, ссылка.

## Стандарты канала
- Голос: Kokoro, `am_michael`, скорость 0.95. Числа и годы перед озвучкой переводятся в слова.
- Кадры: Wikimedia Commons (Public Domain, CC0, CC BY, CC BY-SA, Open Government Licence v3.0 — британская гослицензия, разрешает коммерческое использование с указанием источника), госсайты США (NASA, USGS и др.), карты кодом по данным Natural Earth. Без лицензий NC и ND, без водяных знаков, без тел и жертв, без чужих видео с YouTube.
- Готовое видео целиком не кладётся в git: отправь его Алану файлом в своём чате, а если файл слишком большой для чата — загрузи как asset черновика GitHub Release в этом репозитории. В git кладётся только сжатая копия для проверки.
- Тексты для YouTube (название, описание, главы, теги) лежат в `videoNN/youtube/description.txt`.
- Видео: 1920×1080, 30 fps, H.264 + AAC.
- План канала и сценарии: документ «Forbidden Earth — план канала» в claude.ai.
