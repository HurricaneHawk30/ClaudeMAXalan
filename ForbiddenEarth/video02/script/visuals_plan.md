# video02 — Lost Cities That Were Found Again: план кадров

Название: **10 Lost Cities That Were Found Again (And One That Never Was)**. Текст диктора — `script_original.txt` (13 разделов, ~1814 слов, ≈13 мин).

Правила кадров — как в video01 (README, задачи 2–3), плюс для этого видео:
- без гипсовых слепков людей из Помпей и других останков;
- без портретов реальных людей (Бингем, Шлиман, Буркхардт, Олд-Томас и др.) — показываем места, карты, гравюры, находки, архивные снимки местности;
- старинные иллюстрации к «Илиаде» — только без сцен смерти и крови.
